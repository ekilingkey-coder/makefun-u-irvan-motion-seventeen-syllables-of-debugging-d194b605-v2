# Seventeen Syllables of Debugging

One haiku about debugging, written byte-for-byte to `/output/entry.txt` by `main.py` (Python 3 standard library only, offline, deterministic).

Run `python3 main.py` to write the entry; run `python3 main.py --check` to read it back and report a byte-for-byte match.

`research.md` holds the 25 scored candidates, the judge-seat critique and the choice; `title.txt` holds the public title.
